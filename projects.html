3.1 — Digital Card

Current · for sale

A custom NFC business card with an e-paper panel, drawn from a blank sheet in KiCad. ESP32-C3, USB-C charging, a Li-Po cell and an antenna strip on a 71.82 × 36.30 mm board, inside a printed shell with 0.30 mm clearance around it. Three case variants — card, desk nameplate and conference badge — share one tray, cover and four-screw pattern, so any board fits any shell.

KiCad · ESP32-C3 · e-paper · NFC · FreeCAD · PLA

3.2 — Smart Helmet, HUD navigation

Graduation project

An ESP32-based motorcycle helmet that projects turn-by-turn directions onto a transparent OLED in the rider's field of view, so navigation never means looking down at a phone. A companion Android app pulls the route from the Google Maps API and feeds each instruction over BLE as the rider approaches it.

ESP32 · BLE · transparent OLED · Android · Google Maps API · C++

3.3 — Digital Lock System

FPGA

A secure digital lock implemented in VHDL on FPGA — password authentication driven by a state machine, with the access-control logic written out explicitly rather than leaned on a microcontroller library. Simulated and synthesised in Xilinx ISE.

VHDL · FPGA · Xilinx ISE

3.4 — Temperature-Controlled Fan

Microcontroller

A PIC-based cooling system that reads ambient conditions from an LM35 and a DHT11 and adjusts DC fan speed to match, with the current reading and duty shown live on an LCD.

PIC · MikroC · LM35 · DHT11 · LCD

3.5 — Arduino Weather Station

Sensing

A multi-sensor station logging temperature, humidity and rainfall, with all three shown live on an LCD — built for collecting environmental data over long stretches.

Arduino UNO · DHT11 · rain sensor · LCD · C++

3.6 — Motion Sensor Security System

Sensing

A motion-activated alarm using a PIR sensor to spot movement, raising both visual and audible alerts and reporting state on an LCD.

Arduino UNO · PIR · buzzer · LED · LCD

3.7 — Pick-and-Place Robotic Arm

Simulation

A 6-DOF arm simulated in RoboDK for automated pick-and-place on an industrial line, working through forward and inverse kinematics to place the end effector precisely.

RoboDK · 6-DOF · forward & inverse kinematics
